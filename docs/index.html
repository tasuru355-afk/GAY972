Luật Chơi Kéo Co Trắc Nghiệm

🎯 Mục tiêu đối kháng

Hai đội Xanh và Đỏ thi đấu trả lời 10 câu hỏi trắc nghiệm song song. Mỗi câu trả lời sẽ tác động trực tiếp đến lực kéo sợi dây trên sân đấu.

⚖️ Cơ chế tính điểm & Lực kéo

  • Trả lời Đúng: Cộng +100 điểm và kéo dây về phía đội mình.
  • Trả lời Sai: Bị trừ -50 điểm và bị lùi chân, dây nghiêng về phía đối thủ.
  • Bỏ qua câu: Bị trừ -50 điểm, hiển thị ngay đáp án đúng và lời giải chi tiết.

🛠️ Công nghệ thuần túy

Toàn bộ cơ chế tính điểm động (CSS Counters), phản hồi câu hỏi đúng/sai, di chuyển dây kéo và mở popup đều hoạt động 100% bằng HTML & CSS.

Deploy Lên GitHub Pages (Chỉ HTML, CSS)

Dự án hiện tại chỉ gồm 2 file tĩnh duy nhất: index.html và style.css. Bạn có thể deploy theo 2 cách cực kỳ nhanh:

Cách 1: Kéo thả 2 file vào Repository mới (Dành cho người mới)

1. Tạo một GitHub Repository mới hoàn toàn trống.

2. Tải trực tiếp 2 file index.html và style.css lên.

3. Vào Settings ➔ Pages ➔ Chọn nhánh main và thư mục / (root) ➔ Bấm Save.

4. Web sẽ chạy ngay lập tức!

Cách 2: Đẩy cả thư mục này lên GitHub

Chỉ cần git push lên repo, bật GitHub Pages từ nhánh main là trang web của bạn đã online khắp thế giới.

✅ Không cần Node.js, không cần npm build, không có file JavaScript. Bạn có thể mở trực tiếp file index.html trên máy tính bằng Google Chrome, Cốc Cốc, Safari hay Edge để chơi offline ngay lập tức!
